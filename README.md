# Prabhakar Singh: academic portfolio

Static site for Professor Prabhakar Singh, Department of Physics, IIT (BHU) Varanasi.
No build step: open `index.html`, or serve the folder with any static server.

- `js/data.js`: all text content (publications, group, projects, awards). Edit this to update the site.
- `assets/portrait.jpg`: drop the professor's photo here (about 4:5, 640x800 or larger). Until then a monogram shows.
- `css/style.css`: design. `js/main.js`: renders the data and small interactions.

Deploy: GitHub Pages, branch `main`, folder `/ (root)`.
